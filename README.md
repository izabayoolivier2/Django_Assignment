# Django_Assignment
# Overview

This is a simple Task Management application built with Django. The application allows users to register, log in, create tasks, mark tasks as completed, search and filter tasks, and manage their task lists efficiently. The UI is styled minimally, following assignment requirements, with a user-friendly design.

#Features

-User authentication (Login, Register, Logout, Password Recovery)
-Create, update, and delete tasks
-Mark tasks as completed
-Search and filter tasks by title or status


#Setup Instructions to run the project locally
Python (>=3.8)
pip (Python package manager)
virtualenv (optional but recommended)
Git


#Database: SQLite is used as the default database.


#Approach Used

Django Framework: We leveraged Django’s built-in features to handle authentication and task management.
Minimal CSS Styling: We applied minimal custom styles to enhance usability while adhering to assignment guidelines.
Template-Based UI: Django templates were used to keep the frontend dynamic.
Animations & UI Improvements: We included subtle animations and images to improve user experience.
